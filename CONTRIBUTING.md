# Contributing

## Getting Started
1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/ace-online-ide`
3. Install dependencies: `npm install`
4. Start the server: `npm start`

## Project Structure
- `index.html` — Main editor UI
- `kitchen-sink.html` — Full demo page with all features
- `server1.js` — Express backend API for code execution
- `texteditor.js` — Editor initialization and language/theme helpers
- `webpack-resolver.js` — Module resolution config
- `src/` — Ace editor source files
- `src-min/` — Minified Ace editor files
- `assets/` — Static assets (CSS, images)
- `demo/` — Demo scripts and examples

## Submitting Changes
1. Create a feature branch: `git checkout -b feature/my-feature`
2. Commit your changes: `git commit -m "Add my feature"`
3. Push and open a Pull Request
